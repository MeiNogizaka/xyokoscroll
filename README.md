# xyokoscroll

X（旧 Twitter）の画像カルーセルの上にマウスがあるときだけ、ホイールの上下を前後の画像への移動にします。画像の外（投稿テキスト、返信、サイドバー、タイムラインの空白）では、今までどおりページが縦にスクロールします。

下に回せば次の画像、上に回せば前の画像です。最初と最後の画像では、それ以上送れない方向のホイールをタイムラインの縦スクロールに戻すかどうかを設定で選べます。初期値は戻すです。

## インストール

Chrome と Edge のどちらも、同じフォルダを読み込みます。

1. ブラウザで `chrome://extensions`（Edge は `edge://extensions`）を開く。
2. デベロッパー モードをオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダ（`xyokoscroll`）を選ぶ。
4. `https://x.com/` を開き直す。

更新したあとは、拡張機能の画面で再読み込みしてから X のタブも読み込み直してください。

## 設定

ツールバーの拡張機能アイコンを押すと、設定が開きます。拡張機能の詳細にある「拡張機能のオプション」からも同じ画面です。

「最初・最後の画像の先は、タイムラインを縦スクロールする」

- オン（初期値）: 端の画像まで送ったあとは、同じ方向のホイールでタイムラインが動きます。
- オフ: 画像の上では端で止まります。タイムラインを動かすには、カーソルを画像の外に出します。

切り替えると、開いている X のタブへすぐ反映されます。

設定画面の「言語」では、説明文を「ブラウザの言語」「日本語」「English」から選べます。初期値はブラウザの言語です。日本語のブラウザでは日本語、それ以外では英語になります。

拡張機能の一覧に出る説明文と、アイコンにマウスを乗せたときの名前は、ブラウザの表示言語に従います。設定画面の言語切り替えとは別です。日本語のブラウザでは日本語、それ以外では英語です。
